# Obxod

Обход DPI-блокировок под Windows. Открывает сайты, которые провайдер режет **по
имени хоста**: на ходу подменяет имя в TLS-приветствии через драйвер WinDivert.
Один проект, две формы — `obxod-ui` (окно) и `obxod` (консоль).

## Что умеет

- Один файл `obxod-ui.exe` — драйвер вшит и распаковывается рядом при первом
  запуске.
- Кнопка включает и выключает обход.
- Выбор способа из проверенных пресетов; у разных провайдеров работают разные,
  выбранный способ запоминается.
- Свои сайты: добавляйте и убирайте домены сверх встроенного списка.
- Строка скорости, вкладка логов (с кнопкой «Скопировать»), значок в трее
  (крестик сворачивает туда) и необязательный автозапуск с Windows.

## Как пользоваться

1. Запустите `obxod-ui.exe` и разрешите права администратора — драйверу они нужны.
2. Нажмите **Включить**. Откройте заблокированный сайт — он должен загрузиться.
3. Не открылся — выберите другой **способ**: у разных провайдеров работают разные.
4. Чтобы охватить больше сайтов, добавьте их домены на вкладке **Сайты**.

При первом запуске Windows может сказать «неизвестный издатель» (программа без
подписи) — нажмите «Подробнее», затем «Всё равно запустить».

## Способы

Пресеты — это сочетания проверенных приёмов движка, каждый под свой тип
блокировки: Обычный, С повторами, Подпись, Разрез, Агрессивный. Не подошёл один —
попробуйте другой: универсального, работающего везде, нет.

## Чего не умеет

Открывает то, что режут **по имени**. Он **не**:

- ускоряет то, что не блокируют — медленная загрузка с нережущегося сайта это ваш
  канал, а не цензура;
- обходит блокировку **по IP** — часть сервисов (Telegram, часть Instagram)
  режут по адресу, и подмена имени до них не достаёт. Для такого нужен VPN или
  собственный прокси приложения (у Telegram есть встроенный MTProxy в настройках).

Какого типа блокировка у сайта — покажет `obxod.exe -check example.com`.

## Сборка окна

Нужен Go, C-компилятор (например w64devkit) и включённый cgo:

    go env -w CGO_ENABLED=1
    go install github.com/akavel/rsrc@latest
    go generate ./cmd/obxod-ui
    go build -ldflags -H=windowsgui -o obxod-ui.exe ./cmd/obxod-ui

Рядом с `cmd/obxod-ui/main.go` должны лежать `WinDivert.dll`, `WinDivert64.sys`
и `ACTIVE_DISCORD_UDP.bin` — они встраиваются через `//go:embed`.

## Консоль

    go build ./cmd/obxod
    obxod.exe -check discord.com
    obxod.exe -wet -noquic -rules rules.txt

Флаги — запустите `obxod.exe` без аргументов; синтаксис правил — в коде.
