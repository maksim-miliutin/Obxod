# Obxod

Обход DPI-блокировок под Windows: Discord, YouTube, Telegram и другое. Движок на чистом
Go без зависимостей: рассогласовывает TLS-приветствие через драйвер WinDivert, так что
блокировка по имени не видит целого хелло. Один проект, две формы — `obxod-ui` (окно) и
`obxod` (консоль).

## Что умеет

- Один файл `obxod-ui.exe` — драйвер и манифест администратора вшиты внутрь.
- Кнопка включает и выключает обход.
- **Подбор**: вкладка «Подбор» сама прогоняет каждый способ пробами и оставляет тот, что
  лучше работает у твоего провайдера, гадать не нужно.
- Пятнадцать проверенных способов; смена способа происходит **без разрыва соединений** —
  драйвер не перезапускается.
- Иконка в трее: по крестику окно прячется туда, обход продолжает работать.
- Игнор приложения по имени или папке: obxod не трогает его трафик — полезно для VPN
  вроде Radmin, который пробивает NAT через STUN и иначе конфликтует.
- Свои сайты сверх встроенного списка, строка скорости, вкладка логов (с кнопкой
  «Скопировать»), автозапуск с Windows, русский и английский.

## Как пользоваться

1. Запусти `obxod-ui.exe` и разреши права администратора — драйверу они нужны.
2. Нажми **Включить**. Открой заблокированный сайт — он должен загрузиться.
3. Если сайт упрямится, открой вкладку **Подбор** и дай ей выбрать лучший способ, либо
   выбери вручную на вкладке **Методы**.
4. Чтобы охватить больше сайтов, добавь их домены на вкладке **Сайты**.

Запускай подбор, когда **не** сидишь активно на сайте: он пробует способы на живом
трафике и может прервать открытую сессию. Дай ему устаканиться, потом пользуйся.

При первом запуске Windows может сказать «неизвестный издатель» (программа без подписи) —
нажми «Подробнее», затем «Всё равно запустить».

## Способы

Пятнадцать способов, каждый проверен на живом злом DPI, в списке сгруппированы по
семействам: **OV** накладывает записанный хелло поверх потока (seqovl), **DC** шлёт
обманку-хелло вперёд (с трюками по контрольной сумме, ack или sequence), **SW** подменяет
имя сайта на месте, **FR** фрагментирует хелло. У разных провайдеров работают разные, а
DPI со временем меняется, так что подбор это простой путь; что делает каждый, написано в
описании в окне. QUIC (http/3) фейкается для сайтов, которым это нужно (картинки Discord
и подобное), а у голоса Discord свой UDP-обход.

## Чего не умеет

Открывает то, что режут **по имени хоста**. Он **не**:

- ускоряет то, что не блокируют — медленная загрузка с нережущегося сайта это твой
  канал, а не цензура;
- обходит блокировку **по IP** — часть сервисов (Telegram, часть Instagram) режут по
  адресу, и подмена имени до них не достаёт. Для такого нужен VPN или собственный прокси
  приложения (у Telegram есть встроенный MTProxy в настройках).

Какого типа блокировка у сайта — покажет `obxod.exe -check example.com`.

## Сборка окна

Нужен Go, C-компилятор (например w64devkit) и включённый cgo:

    go env -w CGO_ENABLED=1
    go install github.com/akavel/rsrc@latest
    go generate ./cmd/obxod-ui
    go build -ldflags -H=windowsgui -o obxod-ui.exe ./cmd/obxod-ui

Рядом с `cmd/obxod-ui/main.go` должны лежать `WinDivert.dll`, `WinDivert64.sys` и
остальные вшитые ресурсы (записанный UDP, иконка, шрифты) — они встраиваются через
`//go:embed`.

## Консоль

    go build ./cmd/obxod
    obxod.exe -check discord.com
    obxod.exe -wet -noquic -rules rules.txt

Флаги — запусти `obxod.exe` без аргументов; синтаксис правил — в коде.
